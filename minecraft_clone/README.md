# Python Minecraft Clone

Простой клон Minecraft, написанный на Python с использованием игрового движка `ursina`.
В игре реализована генерация мира, возможность ходить, прыгать, а также ставить и ломать блоки различных типов.

## Требования
Для запуска игры вам потребуется установленный **Python 3.6** или новее.

## Инструкция по установке и запуску на Windows

### Шаг 1: Установка Python
1. Перейдите на официальный сайт Python: [python.org/downloads](https://www.python.org/downloads/)
2. Скачайте последнюю версию для Windows.
3. Запустите скачанный установщик. **ОЧЕНЬ ВАЖНО:** на первом экране установки обязательно поставьте галочку **"Add Python to PATH"** (Добавить Python в PATH).
4. Нажмите "Install Now" и дождитесь окончания установки.

### Шаг 2: Установка зависимостей
1. Откройте командную строку (Командная строка или PowerShell). Для этого нажмите `Win + R`, введите `cmd` и нажмите Enter.
2. Установите необходимые библиотеки, введя следующую команду и нажав Enter:
   ```bash
   pip install ursina Pillow
   ```
   Дождитесь окончания установки (это может занять несколько минут).

### Шаг 3: Генерация текстур и запуск игры
1. Скачайте эту папку с игрой (`minecraft_clone`) себе на компьютер.
2. В командной строке перейдите в папку с игрой. Например, если вы сохранили её на рабочий стол, введите:
   ```bash
   cd Desktop\minecraft_clone
   ```
3. Сгенерируйте текстуры блоков, выполнив команду:
   ```bash
   python generate_textures.py
   ```
4. Запустите саму игру:
   ```bash
   python main.py
   ```

## Управление в игре
* **W, A, S, D** - Перемещение
* **Пробел** - Прыжок
* **Мышь** - Осмотр
* **Левая кнопка мыши** - Сломать блок
* **Правая кнопка мыши** - Поставить блок
* **Клавиши 1-5** - Выбор типа блока:
  * 1: Трава (Grass)
  * 2: Камень (Stone)
  * 3: Кирпич (Brick)
  * 4: Земля (Dirt)
  * 5: Дерево (Wood)
* **Esc** - Выход из игры (или освободить курсор мыши)
