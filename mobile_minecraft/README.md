# Mobile 3D Minecraft Clone (.APK)

Полноценная 3D-версия Minecraft-подобной игры, созданная для игры на Android-смартфонах.
Игра написана на высокопроизводительном движке **Three.js** и упакована в настоящее нативное Android-приложение, поэтому работает очень плавно и быстро!

## Фичи
- **Сенсорное управление**:
  - Левая половина экрана: Джойстик для перемещения.
  - Правая половина экрана: Свайпы для поворота камеры.
- **Кнопки действий**: JUMP (Прыжок), BUILD (Построить), BREAK (Сломать).
- **Инвентарь**: Сверху экрана можно выбрать тип блока (Трава, Камень, Земля, Дерево).
- Генерация мира (холмы).
- Физика (гравитация, коллизии с землей).

## 📱 КАК СКАЧАТЬ И УСТАНОВИТЬ APK

Поскольку собрать Android-приложение на обычном компьютере без программ (Android Studio) сложно, я настроил **автоматическую сборку игры (Магию!) прямо здесь, на GitHub**.

1. Зайдите в ваш репозиторий на сайте GitHub (там, где лежит этот код).
2. Наверху под названием репозитория найдите вкладку **"Actions"** (рядом с "Code" и "Pull requests") и нажмите на неё.
3. Выберите слева в списке **"Build Android APK"**.
4. Нажмите на самый верхний (самый свежий) зеленый значок с галочкой в списке запусков.
5. Прокрутите страницу в самый низ до раздела **"Artifacts"**.
6. Нажмите на **`Minecraft-Clone-APK`**. Скачается ZIP-архив.
7. Распакуйте этот архив — внутри лежит готовый файл **`app-debug.apk`**.
8. Перекиньте его на свой Android-телефон (через Telegram, USB или Google Drive) и установите!

*(Если телефон спросит разрешение на установку из неизвестных источников, разрешите это)*

## Если вы хотите запустить игру на ПК прямо сейчас:
Вы можете открыть игру прямо в браузере, не устанавливая APK:
1. Зайдите в папку `mobile_minecraft/app/src/main/assets`
2. Откройте файл `index.html` в Chrome или любом другом браузере.
3. Включите режим "Мобильного устройства" (F12 -> Иконка телефона), обновите страницу и играйте!
